# Water Quality Prediction using Machine Learning

## Project

This project predicts whether water is safe to drink using Machine Learning.

Dataset:
water_potability.csv

Target:
Potability

0 = Not Safe
1 = Safe

## Algorithms

- Logistic Regression
- Decision Tree

## Evaluation

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC Curve

## Hyperparameter Tuning

- GridSearchCV

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
